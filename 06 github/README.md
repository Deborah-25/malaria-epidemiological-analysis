Malaria Cases: Epidemiological Data Analysis

 Project Overview
This beginner portfolio project demonstrates how spreadsheet tools can be used to clean, summarize, analyze, and visualize public health data.

The project uses a synthetic dataset containing 100 fictional patient records. It is intended for learning and portfolio demonstration only.

Objectives
- Clean and organize a health-related dataset.
- Identify missing values and standardize inconsistent entries.
- Summarize positive and negative malaria test results.
- Compare positivity rates by sex, age group, and community.
- Create charts and communicate findings in a written report.

Tools Used
- WPS Spreadsheet / Microsoft Excel
- PivotTables
- Spreadsheet formulas
- Data visualization
- Word processing and PDF reporting

Dataset
The dataset contains 100 synthetic records and includes patient ID, age, sex, community, month, malaria test result, fever status, treatment, and outcome.

No real patient information was used.

Key Findings
- Overall: 52 positive and 48 negative test results.
- By sex: 48.3% positivity among females and 57.5% among males.
- By age group: the highest observed positivity rate was 68.8% among those aged 15–24.
- By community: Communities A and B each had a positivity rate of 58.3%.

Three records had missing ages. These records were not assigned guessed ages and were excluded from age-group comparisons.

Project Files
- Raw dataset
- Cleaned dataset
- Analysis workbook
- Community positivity chart
- Written report in Word and PDF formats

Limitations
This is a small synthetic dataset created for practice. The results do not represent real malaria prevalence, actual patients, or actual communities. The findings are descriptive and do not establish causation or statistical significance.
